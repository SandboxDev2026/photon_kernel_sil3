## 3. 审计验收标准

### 3.1 必须全部通过（P0）

- 所有 P0 测试项必须 100% 通过
- 0 沙盒逃逸、0 权限提升、0 数据泄露、0 网络隔离绕过
- 发现的 P0 漏洞必须修复并回归测试通过

### 3.2 重要项通过率要求（P1）

- P1 测试项通过率 ≥ 95%
- 未通过项必须有风险接受记录和缓解措施

### 3.3 增强项建议（P2）

- P2 测试项建议通过率 ≥ 80%
- 未通过项记录为技术债务，安排后续迭代修复
