## 二、本轮落地：DefenseRulePersistence 防御规则持久化与熔断

### 2.1 模块说明

针对清单第2块"闭环补齐"中的"防御规则持久化+下发回写链路，附带规则熔断与回滚"，实现DefenseRulePersistence模块（473行）。

### 2.2 核心能力

| 能力 | 说明 |
|------|------|
| 规则持久化 | 规则状态写入JSON文件，重启后恢复 |
| 规则版本管理 | 每次部署生成新版本，支持回滚到任意历史版本 |
| 熔断器 | 部署后监控规则效果，失败次数超阈值自动熔断 |
| 自动回滚 | 熔断后自动回滚到上一稳定版本 |
| 效果评估 | 统计触发次数、拦截成功率、误报率 |
| 半开恢复 | 熔断冷却后尝试恢复，少量流量测试 |
| 监控期→ACTIVE | 部署后进入监控期，≥10次触发且成功率≥80%转为ACTIVE |

### 2.3 规则状态机

```
DRAFT → PENDING → DEPLOYED → MONITORING → ACTIVE
                          ↓                    ↓
                    CIRCUIT_BROKEN ←── 失败超阈值
                          ↓
                    ROLLED_BACK (自动回滚)
```

### 2.4 熔断器状态机

```
CLOSED(正常生效) → 失败≥阈值 → OPEN(熔断禁用)
     ↑                              ↓
     └── 半开成功≥阈值 ←── HALF_OPEN(冷却后尝试)
```
