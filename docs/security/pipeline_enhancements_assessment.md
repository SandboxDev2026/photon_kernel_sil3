# PhotonBox 安全事件流水线增强模块评估报告

**日期**: 2026-09-03
**范围**: PipelineEnhancements 增强模块（去重缓存 TTL+容量上限 + 熔断告警+人工确认）

---

## 一、模块说明

针对用户提出的两个优化点：
1. 去重持久化的 TTL 和容量上限 — 确认磁盘不会无限增长，设置过期淘汰和容量上限告警
2. 规则熔断后的人工确认机制 — 熔断事件有告警，避免规则静默失效没人知道

实现 PipelineEnhancements 模块（521 行），包含两个核心组件。

## 二、DuplicateCacheManager 去重缓存管理

### 核心能力

| 能力 | 说明 |
|------|------|
| TTL 过期淘汰 | 每个 event_id 记录存入时间，超过 TTL 自动淘汰 |
| 容量上限 | 设置最大缓存条数，超过上限时告警并淘汰最旧的 |
| 容量预警 | 达到 80% 时发出 WARNING 告警 |
| 容量严重 | 达到 95% 时发出 CRITICAL 告警并自动淘汰最旧 10% |
| 告警冷却 | 告警冷却 5 分钟，避免告警风暴 |
| 持久化 | 缓存状态保存到磁盘，支持重启恢复（加载时过滤过期条目） |
| 统计指标 | 缓存命中率、淘汰数、告警次数 |

### 验证结果

| 测试项 | 结果 |
|--------|------|
| 基本去重功能 | 通过 |
| TTL 过期淘汰（1秒 TTL，等待 1.5 秒） | 通过（2 个全部过期） |
| 容量上限告警（上限 10，添加 12 个） | 通过（3 次预警 + 5 次严重 + 自动淘汰 5 个） |
| 告警回调 | 通过（收到 1 个告警回调） |
| 持久化+重启恢复 | 通过（2 个事件恢复） |

## 三、CircuitBreakerAlertManager 熔断告警管理

### 核心能力

| 能力 | 说明 |
|------|------|
| 熔断开告警 | 规则熔断时自动发出告警，包含规则 ID、失败次数、原因、规则配置 |
| 告警持久化 | 告警保存到磁盘，支持查询和审计 |
| 人工确认 | 熔断后需要人工确认才能恢复（可选，默认自动恢复） |
| 恢复验证 | 恢复后验证规则是否正常工作 |
| 告警统计 | 按规则/类型/严重等级统计 |
| 告警状态机 | NEW → ACKNOWLEDGED → RESOLVED |
| 告警数量限制 | 最多 10000 条，超过自动清理最旧的 |

### 验证结果

| 测试项 | 结果 |
|--------|------|
| 熔断开告警 | 通过（包含失败次数、原因、规则配置） |
| 自动恢复模式（不需要确认） | 通过 |
| 人工确认模式（未确认时恢复失败） | 通过（返回 requires_manual_acknowledgment） |
| 人工确认后恢复 | 通过 |
| 待确认告警查询 | 通过 |
| 告警统计 | 通过 |
