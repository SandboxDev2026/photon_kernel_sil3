## 一、重构说明

## 二、重构详情

### 2.1 EventInputValidator.validate() 重构为校验链模式

| 指标 | 重构前 | 重构后 |
|------|--------|--------|
| 主函数行数 | 67 行 | 28 行 |
| 子函数数量 | 0 | 1 个（_build_validation_chain） |
| 重复模式 | 8 个"检查→拒绝"重复块 | 循环统一处理 |
| 可扩展性 | 新增校验步骤需修改主函数 | 只需在链中添加步骤 |

重构核心：将 8 个依次执行的校验步骤（来源校验→频率限制→结构校验→内容校验→恶意模式检测→签名验证→去重→清洗）重构为校验步骤列表 + 循环执行模式。条件步骤（签名验证、去重）根据配置动态加入。

修复 red_blue_adversary.py 中 15 处 B311（标准伪随机数生成器）LOW 问题。这些 random 调用用于红蓝对抗模拟和变异逻辑，不是安全加密目的，添加 # nosec B311 注释说明。
