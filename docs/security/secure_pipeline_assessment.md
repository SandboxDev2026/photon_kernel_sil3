## 一、模块说明

SecureEventPipeline 将 EventInputValidator 挂载到 RealDataAdapter 事件入口，实现事件去重持久化，集成防御规则下发链路。

完整链路：
```
日志消费层 → EventInputValidator(8维校验+去重持久化)
  → RealDataAdapter(标准化安全事件)
  → RedBlueAdversaryTrainer(红蓝对抗推演)
  → DefenseRulePersistence(规则持久化+熔断+回滚)
  → DefenseRuleExecutor(规则部署到执行层)
```

## 二、核心能力

| 能力 | 说明 |
|------|------|
| 事件入口校验 | EventInputValidator 8维校验体系挂载到 RealDataAdapter 入口 |
| 事件去重持久化 | 去重缓存保存到磁盘，进程重启后恢复，解决重启丢失去重状态 |
| 防御规则下发 | 红蓝对抗输出规则落地到 LightPool/StrongPool 执行层 |
| 规则熔断 | 部署后监控规则效果，失败次数超阈值自动熔断禁用 |
| 自动回滚 | 熔断后自动回滚到上一稳定版本 |
| 状态持久化 | 全部状态（去重缓存+规则状态）持久化到磁盘 |
